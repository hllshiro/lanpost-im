# 已知限制与当前边界

更新：2026-10-26（0.1.0）

0.1.0 是纯标准 IPMSG 实现。以下边界用于区分“尚未实现”和“回归缺陷”。

## 协议与互通

| 限制 | 现状 | 影响 |
| --- | --- | --- |
| 加密 | 未实现 | 消息、文件名和目录元数据在局域网内明文传输；不参与 RSA/AES 公钥协商 |
| 私有扩展协议 | 不实现 | 只使用标准 IPMSG 命令与选项位，不处理任何厂商私有命令 |
| 发现依赖 UDP 广播 | 已提供种子地址与附加网段 | 禁用广播的 VLAN、企业网络或 VPN 需要手动填写种子地址 |
| 主机列表 | 最小兼容 | GETLIST/ANSLIST 已实现，但多数现代客户端不依赖它；联系人主要仍由 ENTRY/ANSENTRY 建立 |
| 目录断点续传 | 不支持 | 目录传输中断后整目录重来，已接收的半成品会清理 |
| 特殊文件类型 | 跳过 | 符号链接、设备文件、FIFO、资源分支不还原，只记录日志 |
| 扩展属性 | 部分应用 | 应用 mtime 与只读；UID/GID/ACL/FinderInfo 等只解析不生效 |
| 密封消息 | 传输层保密 | 正文仍以明文保存在本地数据库，界面只做遮挡；不是静态加密 |
| 内嵌图片 | 不插入光标处 | 一次邀请最多 10 张、单张 10 MB；图片显示在文字下方，超出降级为普通文件 |
| 文件拒绝 | 已支持 | 接收方拒绝/取消时发 RELEASEFILES，发送方标记为已拒绝 |
| 多网卡联系人 | 已知行为 | 按 `IP|账号` 建键，同一主机可能出现多个同名联系人；有身份码的 lanpost 联系人会复用同一会话 |
| 身份合并 | 尽力而为 | 身份码由首次运行时的硬件 UUID + 账号生成；硬件变化、读不到 UUID、重装后设置丢失或账号不同都会得到新身份。身份码仅内部使用，界面不展示，也暂不提供导入入口 |
| 跨客户端合并 | 仅 lanpost | 只有 lanpost 在 Entry 扩展里发送身份码；内网通、飞秋等没有身份码，仍按 `IP|账号` 分开 |
| 客户端能力识别 | 尽力而为 | 通过报文版本和身份码识别 lanpost/内网通/飞秋；普通标准客户端可能显示为未知第三方，图片/文件夹按钮不额外限制 |
| 第三方客户端提示 | 每次启动一次 | 首次打开非 lanpost 会话时插入一条系统消息；同一进程内不重复，重启后会替换旧提示 |
| 内网通图片/文件夹 | 界面禁用 | 对端识别为内网通时禁用图片和文件夹入口，并在按钮 tooltip 说明；服务端也会拒绝绕过 UI 的调用 |
| 飞秋图片 | 界面禁用 | 对端识别为飞秋时禁用图片入口；文件夹入口仍保留 |
| 自动在线状态 | 固定阈值 | 超过 10 分钟无操作自动忙碌、30 分钟自动离开；仅自动升级手动“在线”状态，手动忙碌/离开不会被覆盖，恢复操作后回到自动切换前的状态 |
| 全局快捷键 | 尽力注册 | 默认 `Ctrl+Alt+W` / `Ctrl+Alt+R`，可在设置中总开关或清空单项；组合被其他程序占用或桌面环境（如 Wayland）不支持时注册失败，仅写日志，界面会在录制时提示占用 |
| 接收目录快捷键 | 启动时路径 | 快捷键打开的是启动时确定的接收目录；修改接收目录后需要重启才能生效 |
| MAC 地址 | 不采集 | 不使用 MAC 作为身份或合并依据 |
| 文件匹配兜底 | 有边界 | 对端不返回正确 packetId/fileId 时，按同 IP 最新待发送任务兜底；多个任务同时等待时需要看日志 |

## 数据与设置

| 限制 | 现状 | 影响 |
| --- | --- | --- |
| 旧数据库 | 自动重建 | 当前 schema 版本为 4；从旧版本升级会清空会话、联系人与文件历史，不提供迁移 |
| 数据目录设置 | 仅环境变量生效 | 设置页的数据目录字段会保存，但主进程实际使用 `LANPOST_DATA_DIR` 或默认 `userData` |
| 开机启动 | 未接入 | 设置项已存在，主进程没有调用 `setLoginItemSettings` |
| 最小化启动 | 未接入 | 设置项已存在，启动窗口逻辑没有读取 |
| 接收后打开 | 未接入 | 设置项已存在，接收完成不会自动打开文件 |
| 接收目录、端口、监听地址 | 重启生效 | 运行中的文件服务或协议引擎不会热切换 |
| 历史保留 | 永久 | `historyRetention` 目前只有永久选项，没有自动清理 |
| 消息搜索、导出 | 未实现 | 只有会话内过滤，没有跨会话全文搜索或导出 |
| 设置搜索 | 未实现 | 设置页按分类浏览 |
| 文件页速度 | 未显示 | 文件页显示百分比和大小，速度只在聊天里的文件卡片显示 |

## 运行环境

| 限制 | 现状 | 影响 |
| --- | --- | --- |
| Windows 第三方安全软件 | 只处理 Windows 防火墙 | 第三方安全软件仍可能拦截入站 2425，需要单独放行 |
| Linux 防火墙 | 仅 ufw/firewalld | deb 安装和设置页修复只处理 ufw/firewalld；自定义 nftables/iptables 需要手动放行 |
| Linux 防火墙状态 | 依赖记录文件 | 非 root 不直接读取 ufw 规则，依据 `/var/lib/lanpost-im/firewall-ports`；外部删除规则后记录可能过期 |
| 改端口后的旧规则 | 不自动清理 | deb 安装时添加的 2425 规则会保留，新端口需要再点一次修复 |
| 安装包防火墙回归 | 未做全新安装 | Windows 安装包已构建、Linux deb 脚本只做了语法校验，仍需真实安装/卸载验证 |
| 文件服务启动失败 | 仅写日志 | 界面没有明确提示，对端可能一直停在等待状态 |
| 监听地址/端口校验 | 无警告 | 允许配置 `127.0.0.1` 或非 2425 端口，可能导致对端无法连接 |
| 受限终端 | 回退 `.dev-data` | Roaming 不可写时数据落在项目目录；日志会记录 `EPERM` |
| 管理员终端 | 不推荐 | Electron 44 在提权环境可能出现 GPU/渲染进程启动失败 |
| GPU/沙箱启动失败 | 需要 `--no-sandbox` | 仅作为环境兜底，不是正式运行方式 |
| 自动化验证 | 只有 Node 侧测试 | 没有 Playwright/UI 自动化；真实对端矩阵仍需人工验证 |
| 真实对端回归 | 部分覆盖 | 单文件外发已实机验证；目录、图片、密封、广播与多客户端矩阵尚未归档 |
| 发布链路 | 未完整验证 | CI 只在 `v*` 标签或手动触发时打包，尚未跑过完整发布链路 |

## 明确不做

- 不实现任何加密或私有协议扩展。
- 不为了兼容而发送厂商私有命令。
- 不为目录、字段或产品名变更编写旧版本数据迁移。
- 不把同一主机的多个网卡联系人强行合并，联系人键保持 `IP|账号`。
- 不创建符号链接或设备节点。
- 不把“已确认送达”当作“对方已读”。
