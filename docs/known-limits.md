# 已知限制与当前边界

这是第一版的边界清单，避免把尚未实现的能力当成回归缺陷。第一版尚未正式发布，目录或命名变更不写数据迁移代码。

## 协议与互通

| 限制                 | 现状     | 影响                                                                                        |
| -------------------- | -------- | ------------------------------------------------------------------------------------------- |
| 私有 ENet 通道       | 未实现   | 群聊、共享文件柜、远程协助、私有文件协商不可用                                              |
| 私有控制载荷         | 未解密   | 9011 发现、ENet 会话和 AES 控制报文无法完整复现                                             |
| 私有文件通道         | 未实现   | 握手只广告 TCP 文件端口，`FILE_TRAN_ENET_PORT = 0`                                          |
| 群聊                 | 未实现   | 3000–3012 私有命令未接入；自有群聊留给扩展协议                                              |
| 共享文件柜、远程协助 | 未实现   | 5000+、4000+ 命令未接入                                                                     |
| 离线消息             | 未实现   | 依赖内网通无服务器版本的离线能力                                                            |
| IPMSG 加密           | 未实现   | 消息和文件元数据在局域网内明文传输                                                          |
| 文件夹传输           | 未实现   | 只支持单个文件，`GETDIRFILES` / 目录附件未接入                                              |
| 文件拒绝             | 本地生效 | IPMSG 没有标准拒绝报文，发送方会停在 `offered`                                              |
| 多网卡联系人         | 已知行为 | 按 IP 和账号建键，同一主机可能出现多个同名联系人                                            |
| 文件匹配兜底         | 有边界   | 对端不返回正确 packetId/fileId 时，按同 IP 最新待发送任务兜底；多个任务同时等待时需要看日志 |

## 数据与设置

| 限制                     | 现状           | 影响                                                                              |
| ------------------------ | -------------- | --------------------------------------------------------------------------------- |
| 数据目录设置             | 仅环境变量生效 | 设置页的数据目录字段会保存，但主进程实际使用 `LANPOST_DATA_DIR` 或默认 `userData` |
| 开机启动                 | 未接入         | 设置项已存在，主进程没有调用 `setLoginItemSettings`                               |
| 最小化启动               | 未接入         | 设置项已存在，启动窗口逻辑没有读取                                                |
| 接收后打开               | 未接入         | 设置项已存在，接收完成不会自动打开文件                                            |
| 接收目录、端口、监听地址 | 重启生效       | 运行中的文件服务或协议引擎不会热切换                                              |
| 历史保留                 | 永久           | `historyRetention` 目前只有永久选项，没有自动清理                                 |
| 消息搜索、导出           | 未实现         | 只有会话列表过滤，没有消息全文搜索或导出                                          |
| 设置搜索                 | 未实现         | 设置页按分类浏览                                                                  |
| 文件页速度               | 未显示         | 文件页显示百分比和大小，速度只在聊天里的文件卡片显示                              |

## 运行环境

| 限制             | 现状                | 影响                                                                                      |
| ---------------- | ------------------- | ----------------------------------------------------------------------------------------- |
| Windows 防火墙   | 安装器未自动加规则  | 开发版 `electron.exe` 和安装版 `lanpost-im.exe` 可能分别需要在防火墙放行入站 TCP/UDP 2425 |
| 受限终端         | 回退 `.dev-data`    | Roaming 不可写时数据落在项目目录；日志会记录 `EPERM`                                      |
| 管理员终端       | 不推荐              | Electron 44 在提权环境可能出现 GPU/渲染进程启动失败                                       |
| GPU/沙箱启动失败 | 需要 `--no-sandbox` | 仅作为环境兜底，不是正式运行方式                                                          |
| 自动化验证       | 只有 Node 侧测试    | CI 跑 typecheck、Vitest 和构建，没有 Playwright/UI 自动化                                 |

## 明确不做

- 不用私有 ENet 通道替代 IPMSG 兼容通道。
- 不在私有控制载荷未解密前广告 ENet 文件端口。
- 不为了目录、产品名或设置字段变更编写旧版本数据迁移。
- 不把同一主机的多个网卡联系人强行合并，联系人键保持 `IP|账号`。
- 不把文件拒绝伪装成成功；发送方停在 `offered` 是当前协议边界。
