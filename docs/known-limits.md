# 已知限制与当前边界

这是第一版的边界清单，避免把尚未实现的能力当成回归缺陷。第一版尚未正式发布，目录或命名变更不写数据迁移代码。

## 协议与互通

| 限制                 | 现状                                 | 影响                                                                                                                                                     |
| -------------------- | ------------------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 私有 ENet 通道       | 唯一通道                             | 文字、文件、图片、文件夹、群聊全部走 NWT 私有协议；IPMSG、飞秋、飞鸽兼容层已移除                                                                         |
| 私有发现             | 已实现                               | UDP 9011 发送 type 1 通告、回复 type 2；广播不可达时用 `network.privateSeeds` 直连                                                                       |
| 私有控制载荷         | 已实现                               | TEA、应用帧与会话状态机已接入；真实样本上 ready、1005、文件与图片均已通过                                                                                |
| 私有通道联系人       | 已支持                               | 只通过私有会话出现的联系人没有 IPMSG 端口，文字、文件和图片都走私有通道                                                                                  |
| 私有文件通道         | 已实现                               | TCP 帧（HELLO/ACK/PATH/DATA）与反向推送已接入；`FILE_TRAN_ENET_PORT = 0`，只走 TCP                                                                       |
| 群聊                 | 已实现                               | 入群、群资料、成员、群文字、群图片、群文件与群文件夹、群管理（建群/拉人/踢人/退群/解散）均已与真实客户端联调通过；群资料的修改还没有入口，只跟随对端变更 |
| 共享文件柜、远程协助 | 未实现                               | 5000+、4000+ 命令未接入                                                                                                                                  |
| 离线消息             | 未实现                               | 依赖内网通无服务器版本的离线能力                                                                                                                         |
| 密封消息             | 未实现                               | NWT 私有 `X_SEND_MSG` 没有对应字段；TEA 只是传输加密，不提供逐条“密封/启封”语义                                                                          |
| 文件夹传输           | 已实现                               | 私有通道收发已接通；发送端连接收方的文件夹端口，接收落盘到接收目录或按昵称子目录                                                                         |
| 文件夹续传           | 未验证                               | 协议里有按项偏移的续传语义，还没在断线场景下验证过                                                                                                       |
| 头像                 | 已实现                               | 私有通道的个人头像可设置，随握手和 `X_CHANGE_INFO` 公布并按 md5 缓存；群头像由群主设置，随 `3002` 推送并由成员按 md5 取图                                 |
| 正在输入             | 未实现                               | `X_SEND_WRITTING(1008)` 只记日志                                                                                                                         |
| 消息撤回             | 未实现                               | 内网通的撤回消息不在已接入的命令里                                                                                                                       |
| 文件拒绝             | 本地生效                             | `OP` 的拒绝/取消取值尚未还原，发送方可能停在等待态；当前只把本地任务标成已拒绝                                                                           |
| 多网卡联系人         | 已知行为                             | 按 IP 和私有用户号建键，同一主机可能出现多个同名联系人                                                                                                   |
| 文件匹配兜底         | 有边界                               | 对端不返回正确 task id/file id 时，按同 IP 最新待发送任务兜底；多个任务同时等待时需要看日志                                                              |

## 数据与设置

| 限制                     | 现状           | 影响                                                                               |
| ------------------------ | -------------- | ---------------------------------------------------------------------------------- |
| 数据目录设置             | 仅环境变量生效 | 设置页的数据目录字段会保存，但主进程实际使用 `LANPOST_DATA_DIR` 或默认 `userData` |
| 开机启动                 | 已接入         | Windows/macOS 使用登录项，Linux 写入 XDG autostart；失败会在设置页提示              |
| 最小化启动               | 已接入         | 启动窗口按 `general.startMinimized` 隐藏，可从托盘或全局快捷键唤出                 |
| 空闲自动离开             | 已接入         | 30 分钟无操作自动切到离开，恢复操作后回到原状态；手动忙碌/离开不被覆盖              |
| 接收后打开               | 未接入         | 设置项已存在，接收完成不会自动打开文件                                             |
| 接收目录、端口、监听地址 | 重启生效       | 运行中的私有服务不会热切换                                                         |
| 历史保留                 | 永久           | `historyRetention` 目前只有永久选项，没有自动清理                                  |
| 消息搜索、导出           | 未实现         | 会话内过滤只匹配已加载的消息（现在整段历史都在内存里），没有全文检索与聊天记录导出 |
| 设置搜索                 | 未实现         | 设置页按分类浏览                                                                   |
| 文件页速度               | 未显示         | 文件页显示百分比和大小，速度只在聊天里的文件卡片显示                               |

## 运行环境

| 限制             | 现状                | 影响                                                                                      |
| ---------------- | ------------------- | ----------------------------------------------------------------------------------------- |
| Windows 防火墙   | 安装器与设置页处理  | NSIS 安装包按程序路径添加入站规则；设置 → 网络 → 防火墙可检测并修复                       |
| Linux 防火墙     | deb/rpm 与设置页处理 | 安装脚本为默认 9011/UDP、9012/UDP、9013/TCP、9014/TCP 添加 ufw/firewalld 规则；设置页可修复 |
| 受限终端         | 回退 `.dev-data`    | Roaming 不可写时数据落在项目目录；日志会记录 `EPERM`                                      |
| 管理员终端       | 不推荐              | Electron 44 在提权环境可能出现 GPU/渲染进程启动失败                                       |
| GPU/沙箱启动失败 | 需要 `--no-sandbox` | 仅作为环境兜底，不是正式运行方式                                                          |
| 自动化验证       | 只有 Node 侧测试    | CI 跑 typecheck、Vitest 和构建，没有 Playwright/UI 自动化                                 |

## 明确不做

- 不实现 IPMSG、飞秋、飞鸽兼容；所有收发只走 NWT 私有协议。
- 不在私有 ENet 通道接入前广告 ENet 文件端口。
- 不为了目录、产品名或设置字段变更编写旧版本数据迁移。
- 不把同一主机的多个网卡联系人强行合并，联系人键保持 IP 与私有用户号。
- 不把文件拒绝伪装成成功；对端通知受限于尚未还原的 `OP` 取值。
